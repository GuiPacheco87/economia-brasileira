# Brasil 2031 — Panorama Econômico

Dashboard interativo sobre possíveis trajetórias da economia brasileira entre 2027 e 2031.

## Conteúdo

- Cenário-base do FMI para PIB, IPCA, Selic e dívida bruta.
- Expectativas do Boletim Focus até 2029, com extensão técnica identificada para 2030–2031.
- Cenários alternativos otimista e adverso.
- Vetores de risco e oportunidade, tabela comparativa e metodologia transparente.

Abra `dist/index.html` no navegador ou sirva a pasta `dist` com um servidor HTTP.

Os dados estão em `data/scenarios.csv` e as referências em `data/sources.md`.

> Conteúdo educacional. Cenários não constituem recomendação de investimento.
